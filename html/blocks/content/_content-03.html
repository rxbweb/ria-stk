Инструкция по оформлению подписки

Инструкция по оформлению подписки на печатную прессу через сайт podpiska.pochta.ru

  1. Выберете журнал и газету из 5 000 изданий:
    1. по индексу,
    2. по теме и профессиональным интересам,
    3. по алфавиту,
    4. по части названия,
    5. из списка самых популярных
    6. по полу и возрасту (детям, женщинам, опытным читателям, мужчинам).
  2. Выберите способ доставки.
  3. Введите данные получателя: адрес доставки, ФИО.
  4. Выберите период подписки.
  5. Пройдите простую процедуру регистрации или авторизуйтесь на сайте.
  6. Оплатите заказ.

Инструкция по оформление подписки онлайн через мобильное приложение Почты России

  1. Зайдите в мобильное приложение Почты России.
  2. В правом нижнем углу выберите раздел «Еще».
  3. Нажмите на строчку «Подписка на журналы и газеты».
  4. Выберите журнал и газету из 5 000 изданий:
    1. по индексу,
    2. по теме и профессиональным интересам,
    3. по алфавиту,
    4. по части названия,
    5. из списка самых популярных,
    6. по полу и возрасту (детям, женщинам, опытным читателям, мужчинам).
  5. Выберите способ доставки.
  6. Введите данные получателя: адрес доставки, ФИО.
  7. Выберите период подписки.
  8. Пройдите простую процедуру регистрации или авторизуйтесь на сайте.
  9. Оплатите заказ.
